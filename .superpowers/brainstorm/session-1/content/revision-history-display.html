How should the new "Pending" update look in the list relative to the official r26?

A

Revision 26 (Update)

Clearly links to the base version while marking it as an update.

  • Uses only official numbers.
  • Might look like a duplicate of the approved r26.
B

Revision 26 (Pending)

Standard pending label in the list.

  • Familiar ERP terminology.
  • Header will still show r26.
C

PENDING / No Number

The row has no number until it is approved.

  • Zero confusion on numbering.
  • Harder to sort or reference specifically.
